## 卷材开卷与余量核销

访问`http://localhost:3038/coils`。数据保存在`data/coil-ledger.json`。

业务代码分三份：

- `rules.js`（规则）：湿度 8~14%、有效期、长度够否、残长偏差阈值 0.5cm、本人不能确认。
- `rolls.js`（卷材档案）：每卷登记批号、长度、湿度和有效期；余额视图。
- `operations.js`（操作）：领料预占、裁切登记、复核确认；待处理与占用模型视图。

流程：

1. 开卷登记批号、长度、湿度、有效期。
2. 领料按索位长度预占，一卷只接一份未完领料；长度不够、湿度越限或过期即停待复核，库存先不扣。
3. 裁切后登记残长和接头数，偏差过半厘米转复核（本人不能确认），否则直接按实报残长核销。
4. 页面显示余额、待处理和占用模型。
